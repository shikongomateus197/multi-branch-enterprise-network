# \# Multi-Branch Enterprise Network Design

# 

# A Cisco Packet Tracer project involving the design and simulation of a multi-branch enterprise network across six locations in Namibia.

# 

# \## Overview

# 

# This project focuses on designing a structured and scalable network for a fictional organisation called \*\*Venus Technologies\*\*.

# 

# The simulated organisation has its headquarters in Windhoek, with five additional branches in Oshakati, Grootfontein, Mariental, Lüderitz and Opuwo.

# 

# The goal was to design a network that allows communication between all six locations while maintaining departmental separation, efficient IP address allocation and secure network administration.

# 

# The project covers network planning, device configuration and network simulation using Cisco Packet Tracer.

# 

# \## Network Features

# 

# \- \*\*Network topology:\*\* Headquarters connected to five remote branches.

# \- \*\*IP addressing:\*\* IPv4 addressing using the 172.27.0.0/19 address block.

# \- \*\*Subnetting:\*\* Variable Length Subnet Masking (VLSM).

# \- \*\*VLANs:\*\* Departmental network segmentation.

# \- \*\*Inter-VLAN routing:\*\* Communication between departmental networks.

# \- \*\*Dynamic routing:\*\* OSPF for routing between branches.

# \- \*\*Network security:\*\* Device authentication and access control.

# \- \*\*Remote administration:\*\* SSH for secure remote device management.

# \- \*\*Loop prevention:\*\* Spanning Tree Protocol (STP).

# \- \*\*Scalability:\*\* Reserved address space for future expansion.

# 

# \## Network Locations

# 

# The simulated network consists of six locations:

# 

# | Location | VLAN Implementation |

# |---|---|

# | Windhoek | Yes |

# | Oshakati | Yes |

# | Lüderitz | Yes |

# | Mariental | Yes |

# | Opuwo | No |

# | Grootfontein | No |

# 

# Windhoek serves as the central site and provides the connection to the simulated ISP.
